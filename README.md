# clash-for-linux

**现代化的 Linux Clash 代理管理工具** 🚀

一键安装、自动更新、TUN/Fake-IP/Redirect 三种代理模式，基于 [mihomo](https://github.com/MetaCubeX/mihomo) 内核。

## 快速开始

```bash
git clone https://github.com/111wukong/clash-for-linux.git
cd clash-for-linux/clash-for-linux
sudo bash install.sh
```

## 特性

- ✨ 一键安装，自动检测架构
- 🎛️ TUN / Fake-IP / Redirect 三种模式一键切换
- 📡 智能订阅管理（base64 解码 + YAML 合并）
- 🔄 每日自动更新（订阅 + Geo + 内核）
- 🖥️ 内置 metacubexd Web 面板
- 🩺 全面诊断工具（`clash doctor`）
- 📊 实时流量统计
- 💾 配置备份/恢复
- 🐳 Docker 支持
- 🛡️ systemd 安全沙箱
